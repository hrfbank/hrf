# أفكار من ألعاب أخرى

> نأخذ **أفكار آليات وتجربة لعب** فقط. ما ننسخ تصميم أي لعبة أو شعارها أو رسوماتها أو أسئلتها.
> كل فكرة نعتمدها تتسجل في `GAME_DESIGN.md`، وأرقامها في `src/game/config.ts`.

## سين جيم (فيديو من المستخدم 2026-11-09)

### اللي لاحظناه
| العنصر | كيف يشتغل عندهم |
|---|---|
| لوحة الفئات | ٦ فئات، كل فئة لها أسئلة بقيم ٢٠٠ / ٤٠٠ / ٦٠٠ (مرتين). السؤال المستخدم يبهت |
| دور الفريق | شريط علوي «دور فريق: ...» |
| أسماء الفرق | الفريقان يكتبون أسماءهم |
| النقاط | مجموع لكل فريق، مع أزرار + و − لتصحيح النقاط يدوياً |
| وسائل المساعدة | ٣ لكل فريق (أيقونات: تبديل، اتصال، وأخرى) |
| بعد كشف الجواب | شاشة «أي فريق جاوب صح؟» بثلاثة أزرار: الفريق الأول / الفريق الثاني / ولا أحد |
| أسئلة صور «من هو المشهور؟» | صورة **مقرّبة جداً** (العيون فقط) لشخصية مشهورة |
| أسئلة خرائط | لقطة خريطة لحي **بدون أسماء** والسؤال «ما اسم هذا النادي/المجمع؟» |
| فئات | سيارات، شعارات، من هو المشهور، لوكيشن، سياحة وسفر، خمّن الصورة |
| مؤقت | عدّاد ظاهر أعلى السؤال مع إيقاف/إعادة |
| راعٍ | شعار جهة راعية ظاهر في اللوحة |

### المعتمد لحروف (وافق المستخدم على الكل 2026-11-09)
| الفكرة | كيف تناسب حروف |
|---|---|
| **«أي فريق جاوب صح؟» + «ولا أحد»** | بعد «اكشف الجواب» يضغط ماسك الجوال على الفريق الصح أو «ولا أحد». أسرع من صح/خطأ ويحل حالة إن الفريقين غلطوا |
| **تصحيح يدوي** | زر تراجع عن آخر خلية، لو انضغط خطأ |
| **أسماء الفرق** | كل فريق يكتب اسمه عند البداية (بدل الأحمر/الأخضر فقط) |
| **صورة تتكشف تدريجياً** | في أسئلة الصور: تبدأ الصورة مقرّبة جداً، وكل تلميح يبعّد الكاميرا أكثر. تجمع فكرة التقريب مع تلميحاتنا المتدرجة |
| **أسئلة خرائط** | لقطة خريطة بدون أسماء: «ما اسم هذه المنطقة؟». مناسبة لـ«مناطق الكويت» و«خرايط». تحتاج مصدر خرائط مرخّص (مثل OpenStreetMap مع ذكر المصدر) |
| **٣ وسائل مساعدة** | عندنا وسيلة واحدة لكل جولة. ممكن نخليها ٣ أنواع يختار منها الفريق، والعدد يتغير من الإعدادات |
| **مكان لراعٍ** | مساحة اختيارية لشعار راعٍ في شاشة اللوحة، تطفى من الإعدادات |

### اللي ما نأخذه
- نظام النقاط ٢٠٠/٤٠٠/٦٠٠ بدل اللوحة السداسية: آلية حروف (الوصل بين الطرفين) هي جوهر لعبتنا.
- أي رسومات أو ألوان أو شعارات أو صياغة أسئلة من سين جيم.

## 2026-11-09 — الهوية البصرية "دفتر الحروف"
- **القرار:** خلفية رملية + حنّائي (`--henna`) + أزرق خليجي (`--sea`) + نقش النجمة الثمانية. خطوط: Reem Kufi للعناوين، Lalezar للحروف المنفردة (البلاطات)، IBM Plex Sans Arabic للنصوص. أرقام هندية (٠١٢) عبر `Intl.NumberFormat("ar-u-nu-arab")`. وضع ليلي يتبع الجهاز ويُحفظ اختياره.
- **السبب:** هوية عربية خليجية بدون صور مولّدة. الحروف هي البطل البصري.
- **البدائل اللي انرفضت:** Reem Kufi للحروف المنفردة (أشكال ي و ه غير واضحة).

## 2026-11-09 — وضع تجريبي (demo)

## 2026-11-09 — مشروع جديد: موقع قاعدة أسئلة "حروف"
- **القرار:** بناء موقع جديد من الصفر (مو تعديل نسخة Manus). React + Vite + TypeScript على Vercel، و Supabase لقاعدة البيانات، و Capacitor لاحقاً لتطبيق الجوال.
- **السبب:** نسخة Manus أسئلتها غير دقيقة. Vite + React يعطي موقع سريع ويتحوّل لتطبيق بنفس الكود.
- **البدائل اللي انرفضت:** تعديل نسخة Manus (رفضها المستخدم). Next.js (أثقل، وما نحتاج سيرفر).

## 2026-11-09 — الأسئلة مربوطة بالحروف + تحقق قبل النشر
- **القرار:** كل سؤال له `letter` = أول حرف من الجواب. كل سؤال يبدأ `pending` ولا يظهر للزوار إلا بعد `verified`. التوليد من سكربت محلي على دفعات صغيرة (مجال + حرف) مع مرحلة تحقق بنموذج أقوى.
- **السبب:** مشكلة Manus كانت دقة الأسئلة. RLS يضمن إن غير المدقق ما يطلع.
- **البدائل اللي انرفضت:** توليد 200 سؤال دفعة وحدة بدون تحقق (طريقة الكود القديم).
- **مفتوح:** هل "ال" التعريف تُحسب؟ (مثلاً "البحرين" حرفها ا أو ب؟) لازم يتحدد قبل سكربت التوليد.

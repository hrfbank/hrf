# خطة نظام أسئلة الصور (مسودة للمراجعة)

> الحالة: خطة بس، ما انكتب كود. تنتظر موافقة صاحب اللعبة على الشكل والاقتراحات والأسئلة المفتوحة.

## ١) وش لقيت في الأبلكيشن

- **التقنيات:** React 18 + Vite + TypeScript. الأسئلة كلها في `data/questions.json`، والموقع منشور كـ Artifact داخل Claude (صفحة واحدة، والصور تنرفع كملفات جنبها من `public/images/` عن طريق `scripts/build-artifact.mjs`).
- **دعم الصور موجود جزئياً:** السؤال يقدر يحمل `image: { file, credit, license, source, alt, crop }`. والمكوّن `src/components/QuestionImage.tsx` يعرض الجزء المقصوص (`crop` نسبي من ٠ إلى ١)، ويوسّعه خطوة مع كل تلميح، ويعرض الصورة كاملة مع الجواب. يعني حركة الـ zoom out موجودة.
- **فئات صور فاضية جاهزة:** «من هو المشهور» (`who-is-famous`)، «خرايط» (`maps`)، «خمّن الصورة» (`guess-image`)، ونوعها `kind: "image"`.
- **طريقة اللعب مختلفة عن المسابقات العادية:** حروف = لوحة سداسية، والجواب لازم يبدأ بحرف الخلية، والمقدم يحكم على جواب شفهي. **ما فيه اختيارات متعددة.** عشان كذا كل سؤال صورة لازم يكون له `letter` (أول حرف من الجواب بدون «ال»)، و`options_ar` ما تستخدمها اللعبة الحالية.
- **حدود النشر الحالية (Artifact):** ٥١١ ملف و٢٥٦ ميغا لكل نسخة، و١٥ ميغا للملف الواحد. صورتين WebP لكل سؤال (حوالي ٦٠ إلى ١٢٠ كيلوبايت) يعني نقدر نوصل تقريباً ٢٠٠ إلى ٢٥٠ سؤال صورة قبل ما نحتاج تخزين ثاني (Supabase Storage لاحقاً).

## ٢) شكل البيانات المقترح

بدل ملف تصدير منفصل، **نوسّع شكل السؤال الحالي** عشان اللعبة تقرا من مصدر واحد، ويظل القديم شغال:

```json
{
  "id": 501,
  "category": "who-is-famous",
  "question": "من هو المشهور؟",
  "answer": "عبدالحسين عبدالرضا",
  "letter": "ع",
  "difficulty": 2,
  "status": "verified",
  "question_type": "image_question",
  "image": {
    "role": "question",
    "reveal_mode": "crop",
    "question_file": "images/a8f3c1_q.webp",
    "answer_file": "images/a8f3c1_a.webp",
    "reveal": { "crop_rect": { "x": 0.31, "y": 0.22, "w": 0.38, "h": 0.12 } },
    "wikidata": "Q12345",
    "source": "https://commons.wikimedia.org/wiki/File:...",
    "credit": "اسم المصوّر",
    "license": "CC BY-SA 4.0",
    "license_url": "https://creativecommons.org/licenses/by-sa/4.0/",
    "modified": true,
    "blind_test": { "guess": "...", "evidence": "...", "verdict": "pass" }
  },
  "options": ["...", "...", "...", "..."],
  "correct_index": 2,
  "extra": "معلومة قصيرة مع الجواب"
}
```

- `file` و`crop` القديمة تظل مقبولة (تتحول تلقائياً إلى `answer_file` و`crop_rect`).
- **إعدادات كل نمط** في `reveal`، والأبلكيشن يسوي الحركة بنفسه من صورة الجواب:
  - `crop`: `crop_rect`. ونطلع كذلك `question_file` مقصوصة ونظيفة بمقاس ٨٠٠×٨٠٠.
  - `mask`: `question_file` (بعد شيل الشعار)، و`answer_file` الأصل.
  - `silhouette`: `question_file` ظل جاهز (يحتاج فصل الخلفية، فما يصير بالـ CSS).
  - `pixelate`: `{ start_block: 48, duration_ms: 20000 }`.
  - `blur`: `{ start_px: 30, duration_ms: 20000 }`.
  - `tiles`: `{ cols: 4, rows: 4, interval_ms: 1500, order: [..] }`.
  - `grayscale`: بدون إعدادات (الإجابة ترجّع الألوان).
- **صور الأسئلة النصية:** نفس الحقل `image` مع `role: "question_decor"` أو `"answer_reveal"`، أو `"no_image": true`.
- `credits.json` يتولد من كل الأسئلة، وتنضاف شاشة «المصادر والتراخيص» في الإعدادات.
- `options` و`correct_index` اختيارية (اللعبة الحالية ما تستخدمها، ونخليها لنمط اختيارات بعدين إذا تبي).

## ٣) الـ pipeline

مجلد مستقل `tools/image-pipeline/` بـ Python، وما يدخل شي منه في حزمة الأبلكيشن:

```
tools/image-pipeline/
  config.yaml            # license_filter: off، user_agent، المقاسات، المعدل (طلب كل ثانية)
  categories/*.yaml      # فئة = ملف: المصدر (SPARQL / Commons / Overpass / Natural Earth)، نص السؤال، أنماط الإخفاء، قواعد الخيارات الغلط
  hrf_img/               # الكود: collect, fetch, process, review, export, validate
  cache/                 # كل تنزيل ينحفظ هنا (ما ينرفع للـ git)
  work/                  # المرشحين والصور الوسيطة و review.json
```

| الأمر | وش يسوي |
|---|---|
| `collect <فئة>` | يسحب العناصر (QID، الاسم العربي، الحقول) ويرتبهم حسب الشهرة (عدد sitelinks). العنصر بدون اسم عربي ينعلّم `needs_ar_name` |
| `fetch` | ينزّل الصور المرشحة (P18 + تصنيف Commons) مع الترخيص والمؤلف، ويرفض الأصغر من ٨٠٠px |
| `process` | قص العين (MediaPipe)، اكتشاف الكتابة (EasyOCR)، شيل الشعارات (OpenCV ثم LaMa)، الأشكال من الحدود (SVG ثم WebP)، WebP ٨٥، أسماء hash، مسح EXIF، الاختبار الأعمى |
| `review` | صفحة المراجعة (انظر السؤال المفتوح ١) |
| `export` | يدمج المعتمد بس في `data/questions.json` و`public/images/` و`credits.json` |
| `validate` | كل فحوصات القسم ٩ (الاسم، المصدر، الخيارات، المقاسات، phash للتكرار، crop داخل الحدود، OCR على صور الديكور) |

**المكتبات الجديدة (في أداة الـ pipeline بس، مو في الأبلكيشن):** requests، PyYAML، Pillow، opencv-python-headless، mediapipe، easyocr (تسحب torch للمعالج)، simple-lama-inpainting، imagehash، shapely، anthropic (للاختبار الأعمى). السبب: كل وحدة تغطي خطوة طلبتها بالاسم، وما فيه بديل خفيف بنفس الجودة.

## ٤) الشبكة والمفاتيح (عائق حالي)

- البيئة الحالية ترفض: `query.wikidata.org`، `www.wikidata.org`، `commons.wikimedia.org`، `upload.wikimedia.org`، `ar.wikipedia.org`، `en.wikipedia.org`، `overpass-api.de`، `naciscdn.org` (Natural Earth). لازم تنضاف قبل `collect`.
- Sentinel-2 يحتاج حساب Copernicus (مجاني) ومفتاح، فنأجله لمرحلة الفئات الإضافية.
- الاختبار الأعمى يحتاج مفتاح Claude API.

## ٥) اقتراحات الصور لكل فئة موجودة

| الفئة (عدد أسئلتها) | أسئلة صور مقترحة | النمط | صور للأسئلة النصية |
|---|---|---|---|
| الكويت (٣٧) | معالم كويتية (الأبراج، قصر السيف، جسر جابر، المباركية)، والكويت قديماً | mask، crop | ديكور: صور تراث عامة. جواب: صورة المعلم |
| مناطق الكويت (١١) | شكل حدود المنطقة | silhouette (شكل) | جواب: الخريطة |
| السعودية (١٢) | معالم (المصمك، الدرعية، العلا) | mask، crop | جواب |
| مناطق السعودية (١٣) | شكل المنطقة أو المدينة | silhouette (شكل) | جواب: الخريطة |
| قصص الأنبياء (١٥) | ما في صور أشخاص أبداً. أماكن مذكورة بس | — | جواب بس لأماكن (الجودي، البحر الميت)، والباقي `no_image` |
| إسلامي (١٤) | المساجد الشهيرة | crop (قبة أو مئذنة) | جواب |
| القرآن (١٨) | ما يناسب | — | `no_image` |
| السيرة (١٣) | أماكن (قباء، أحد، بدر) | crop | جواب بس |
| معلومات عامة (٢٣) | حيوانات وطيور وحشرات وفواكه | crop (زوم)، blur | ديكور حسب الموضوع |
| أمثال وألغاز (١١) | ما يناسب | — | `no_image` |
| لغة وأدب (١٢) | الخطوط العربية (ثلث، نسخ، ديواني، رقعة) | الصورة كاملة | `no_image` للنحو |
| شعر عربي (١٣) / شعر نبطي (٠) | الشعراء المعاصرين بس (القدامى ما لهم صور) | crop (العين) | جواب: صورة الشاعر المعاصر |
| من القائل (١٤) | نفس الشي | crop | جواب |
| ألقاب وكنى (١٦) | مشاهير معاصرين بألقابهم | crop (العين) | جواب |
| مترادفات وتضاد (١١) | ما يناسب | — | `no_image` |
| تاريخ (٢٢) | صور تاريخية ملكية عامة، والكويت قديماً | crop، grayscale | ديكور: خريطة المنطقة. جواب: المكان أو الشخص |
| دول وعواصم (١٢) | أفق المدن، والمدن من الفضاء | silhouette، الصورة كاملة | ديكور: العلم أو خريطة الدولة (مو معلم العاصمة) |
| جغرافيا (١٤) | أشكال الدول، والجزر | silhouette (شكل) | جواب |
| ما هي الدولة (١٢) | الأعلام، والملابس التقليدية، والأكلات | crop، grayscale، mask (عنصر ناقص) | جواب: العلم |
| عملات (١٢) | العملات الورقية والمعدنية بدون الرقم والاسم | crop، mask | ديكور: علم الدولة (مو صورة العملة) |
| من هو المشهور (٠) | مشاهير الكويت والخليج والعرب | crop (العين، ٣ مستويات) | — |
| رياضة (١٣) / كرة قدم عالمية (١٣) | الملاعب، شعارات الأندية، الأطقم، لاعبين | crop، silhouette، grayscale، mask | جواب |
| سيارات (١١) | السيارات (الليت، الشبك، الجنط، أو كاملة بدون شعار)، وشعارات السيارات | crop، mask، silhouette | جواب |
| منتجات (١١) | المنتجات المشهورة، أيقونات التطبيقات، شعارات الماركات | mask، crop، grayscale | جواب |
| مطاعم (١١) | شعارات المطاعم بدون حروف | mask، crop، grayscale | جواب |
| مجمعات (١٢) | واجهات المجمعات بعد شيل اللوحات | mask، crop | جواب |
| مسرحيات كويتية (١٣) / مسلسلات خليجية (١٣) | بوسترات بدون العنوان (المتوفر في ويكيبيديا قليل) | crop، mask | جواب: البوستر |
| ممثلون (١١) | الممثلين | crop (العين) | جواب |
| إكسسوارات نسائية (١١) | قطع التراث (الخلخال، المرتعشة...) من Commons إذا متوفرة | crop | جواب |
| أماكن يزورها الناس (١٢) | المعالم العالمية | mask، crop، tiles | جواب |
| خرايط (٠) | الأشكال كلها (مناطق، دول، جزر) | silhouette (شكل) | — |
| خمّن الصورة (٠) | زوم macro على أي شي (فواكه، حشرات، أدوات) | crop، pixelate، blur | — |

**فئات جديدة مقترحة** (غير اللي في الطلب): طوابع الكويت القديمة (Commons، ملكية عامة)، الحروف العربية بالخط (تناسب «حروف» نفسها: «ما هذا الحرف؟» بخط زخرفي)، شعارات الجهات والوزارات الكويتية، الأبراج والجسور الخليجية من الجو.

**ملاحظة على ترتيب الفئات:** كثير من فئات الطلب تطابق فئات موجودة (المشاهير = من هو المشهور، الأعلام = ما هي الدولة، أشكال الدول = خرايط). أقترح نحطها تحت الفئة الموجودة بدل ما نكرر فئة جديدة، إلا اللي ما لها مكان.

## ٦) ترتيب التنفيذ

1. الشبكة والمفاتيح (القسم ٤).
2. هيكل الـ pipeline + ملفات config للفئات الأساسية الأربع.
3. تجربة: ٢٠ عنصر لكل فئة أساسية → صفحة المراجعة.
4. تعديل الأبلكيشن: أنماط الإخفاء الجديدة في `QuestionImage`، وشاشة المصادر، وصور الأسئلة النصية.
5. بعد اعتمادك للشكل: الفئات الإضافية وتكبير العدد.
6. `tools/image-pipeline/README.md` خطوة بخطوة.

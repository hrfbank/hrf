# أسئلة الصور في حروف

أسئلة الصور جزء من بنك حروف نفسه (`data/questions.json`)، وصورها في `public/images/` وتنرفع مع الموقع.

## التشغيل

```bash
python3 tools/images/build.py            # كل المجموعات
python3 tools/images/build.py kw-area    # مجموعة وحدة
npm run validate
```

- `build.py` يقرأ `sets.json`، ينزّل البيانات (ويخزنها في `tools/images/cache/`)، يرسم الصور SVG بأسماء عشوائية، ويضيف الأسئلة بحالة `pending`. إعادة التشغيل تحدّث الأسئلة اللي ما انراجعت، وما تلمس المعتمد أو المرفوض.
- بعدها صاحب اللعبة يراجع من صفحة **مراجعة أسئلة الصور** (`#/review`) داخل الموقع: اعتماد، رفض، صعوبة، ملاحظة. القرارات تنحفظ في مخزن الصفحة.
- Claude يسحب القرارات ويطبقها: `node tools/images/apply-review.mjs قرارات.json`، ثم البناء والنشر.

## إضافة فئة

مجموعة جديدة في `sets.json` بنوع مدعوم (`kind`). الأنواع الحالية:

| النوع | السؤال | صورة السؤال | صورة الجواب | المصدر |
|---|---|---|---|---|
| `kuwait_area_shape` | ما هي المنطقة / الجزيرة؟ | شكل الحدود بس | الشكل مع المناطق حوله + خريطة الكويت الصغيرة | Kuwait-GeoJSON |
| `country_shape` | ما هي الدولة؟ | شكل الدولة بدون جيرانها | الدولة مع جيرانها | Natural Earth (ملكية عامة) |
| `flag` | علم أي دولة؟ | جزء من العلم (`crop`) أو بدون ألوان (`grayscale`) | العلم كامل | flag-icons (MIT) |

## أنماط الإخفاء في اللعبة (`image.mode`)

- `crop`: جزء يتوسع مع كل تلميح لين تبين الصورة كاملة مع الجواب (`image.crop` نسبي).
- `shape` / `mask` / `silhouette`: نسخة معدّلة جاهزة في `image.question_file`، والجواب يعرض `image.file`.
- `grayscale`: نفس الصورة بدون ألوان، والألوان ترجع مع الجواب.

## قواعد صورة السؤال

ما فيها أي كتابة أو شعار أو دليل يكشف الجواب، واسم الملف عشوائي. لهذا انشال علم البرازيل من التجربة (عليه كتابة).
